# Занятие 3. Циклы, функции и побитовые операции

На прошлом занятии мы вводили данные, выполняли вычисления и выводили результат. Сегодня научимся повторять действия в цикле, вспомним функции и применим сдвиги для работы с отдельными битами числа.

## Цикл `for`

Цикл позволяет выполнить один и тот же фрагмент программы несколько раз. Если количество повторений известно заранее, удобно использовать цикл `for`:

```c
for (начальное_действие; условие; действие_после_итерации){
    // Повторяемые действия
}
```

Один проход тела цикла называется **итерацией**. В следующем примере переменная `index` принимает значения от `0` до `7`, поэтому цикл выполняется восемь раз:

```c
for (int index = 0; index < 8; index++){
    printf("Index: %d\n", index);
}
```

Цикл работает так:

1. Один раз выполняется `int index = 0`.
2. Проверяется условие `index < 8`.
3. Если условие истинно, выполняется тело цикла.
4. Выполняется `index++`, то есть значение `index` увеличивается на единицу.
5. Проверка условия повторяется.

Когда `index` становится равен `8`, условие `index < 8` становится ложным и цикл завершается.

Счётчик можно изменять иначе. Например, следующий цикл перебирает значения от `7` до `0`:

```c
for (int index = 7; index >= 0; index--){
    printf("%d ", index);
}
```

## Функции

Функция объединяет действия, которые имеют отдельное назначение. Она может получать значения через параметры и возвращать результат.

```c
unsigned int calculate_power(unsigned int base, unsigned int exponent){
    unsigned int result = 1;

    for (unsigned int index = 0; index < exponent; index++){
        result *= base;
    }

    return result;
}
```

Функция `calculate_power` получает основание `base` и неотрицательный показатель `exponent`. На каждой итерации текущее значение результата умножается на основание. Если показатель равен нулю, цикл не выполняется и функция возвращает начальное значение `1`.

Вызов функции выглядит так:

```c
unsigned int value = calculate_power(2, 5);
printf("%u\n", value);
```

В результате программа выведет `32`.

В Си символ `^` не означает возведение в степень: это операция побитового исключающего ИЛИ. Для целых неотрицательных показателей в наших заданиях используем функцию `calculate_power`.

## Логические и побитовые операции

Логические операции работают с условиями, а побитовые — с отдельными битами целого числа.

| Назначение | Логическая операция | Побитовая операция |
| --- | --- | --- |
| И | `&&` | `&` |
| ИЛИ | `\|\|` | `\|` |
| НЕ | `!` | `~` |
| Исключающее ИЛИ | Нет отдельного оператора | `^` |

Например, условие проверяет, что индекс находится в допустимом диапазоне от `0` до `7`:

```c
if (bit_index >= 0 && bit_index < 8){
    printf("Correct bit index\n");
}
```

Побитовые операции применяются ко всем битам целого числа:

```text
  0101
| 0011
------
  0111
```

## Сдвиги и битовые маски

Биты восьмибитного значения нумеруются справа налево от `0` до `7`:

```text
Номер бита:  7 6 5 4 3 2 1 0
Значение:    0 0 0 0 0 0 0 1
```

Выражение `1u << bit_index` создаёт маску, в которой установлен только бит с номером `bit_index`:

| `bit_index` | Маска | Значение маски |
| ---: | --- | ---: |
| `0` | `00000001` | `1` |
| `1` | `00000010` | `2` |
| `2` | `00000100` | `4` |
| `3` | `00001000` | `8` |
| `7` | `10000000` | `128` |

Для неотрицательного индекса значение `1u << bit_index` совпадает с соответствующей степенью двойки.

### Установка бита

Чтобы установить выбранный бит в `1`, используем побитовое ИЛИ:

```c
value = value | (1u << bit_index);
```

Эту же операцию можно записать короче:

```c
value |= 1u << bit_index;
```

Остальные биты значения не изменяются.

### Сброс бита

Чтобы сбросить выбранный бит в `0`, инвертируем маску и применяем побитовое И:

```c
value = value & ~(1u << bit_index);
```

Короткая запись:

```c
value &= ~(1u << bit_index);
```

Остальные биты значения также не изменяются.

### Получение значения бита

Сдвинем нужный бит в позицию `0` и оставим только его:

```c
unsigned int bit = (value >> bit_index) & 1u;
```

Результат равен `0`, если бит был сброшен, и `1`, если он был установлен.

## Вывод восьми битов числа

В стандартной функции `printf` нет переносимого спецификатора для двоичного представления. Выведем биты по одному, начиная с бита `7`:

```c
void print_byte(unsigned int value){
    for (int bit_index = 7; bit_index >= 0; bit_index--){
        printf("%u", (value >> bit_index) & 1u);
    }
}
```

Функция ничего не возвращает, поэтому перед её именем указан тип `void`.

## Задание 2 — Таблица степеней

**Условие.** Введите целое основание от `1` до `10`. Выведите значения этого числа в степенях от `0` до `7`. Для вычисления степени напишите отдельную функцию `calculate_power`.

**Пример верного ввода и вывода:**

```text
Input base: 2
2 ^ 0 = 1
2 ^ 1 = 2
2 ^ 2 = 4
2 ^ 3 = 8
2 ^ 4 = 16
2 ^ 5 = 32
2 ^ 6 = 64
2 ^ 7 = 128
```

В строках результата символ `^` используется только как привычное математическое обозначение степени. В выражениях языка Си он имеет другое значение.

Код решения:

```c
#include <stdio.h>


unsigned int calculate_power(unsigned int base, unsigned int exponent){
    unsigned int result = 1;

    for (unsigned int index = 0; index < exponent; index++){
        result *= base;
    }

    return result;
}


int main(){
    unsigned int base;

    printf("Input base from 1 to 10: ");
    scanf("%u", &base);

    if (base < 1u || base > 10u){
        printf("Incorrect base\n");
        return 1;
    }

    for (unsigned int exponent = 0; exponent < 8; exponent++){
        printf("%u ^ %u = %u\n", base, exponent, calculate_power(base, exponent));
    }

    return 0;
}
```

## Задание 3 — Установка выбранного бита

**Условие.** Введите целое значение от `0` до `255` и номер бита от `0` до `7`. Установите выбранный бит в `1`. Выведите исходное и полученное значения в двоичном и десятичном виде.

**Пример верного ввода и вывода:**

```text
Input value from 0 to 255: 8
Input bit index from 0 to 7: 1
Before: 00001000 (8)
After:  00001010 (10)
```

Код решения:

```c
#include <stdio.h>


void print_byte(unsigned int value){
    for (int bit_index = 7; bit_index >= 0; bit_index--){
        printf("%u", (value >> bit_index) & 1u);
    }
}


int main(){
    unsigned int value;
    int bit_index;

    printf("Input value from 0 to 255: ");
    scanf("%u", &value);

    printf("Input bit index from 0 to 7: ");
    scanf("%d", &bit_index);

    if (value > 255u || bit_index < 0 || bit_index > 7){
        printf("Incorrect input\n");
        return 1;
    }

    printf("Before: ");
    print_byte(value);
    printf(" (%u)\n", value);

    value |= 1u << bit_index;

    printf("After:  ");
    print_byte(value);
    printf(" (%u)\n", value);

    return 0;
}
```

## Задание 5 — Кодирование чётности восьми чисел

**Условие.** Введите восемь целых чисел. Каждому числу соответствует бит с индексом от `0` до `7`: первому числу — бит `0`, второму — бит `1` и так далее. Если число чётное, установите соответствующий бит в `1`; если число нечётное, оставьте его равным `0`. Выведите полученную восьмибитовую маску в двоичном, десятичном и шестнадцатеричном виде.

**Пример верного ввода и вывода:**

```text
Input number 1: 2
Input number 2: 3
Input number 3: 4
Input number 4: 5
Input number 5: 7
Input number 6: 8
Input number 7: 10
Input number 8: 11
Binary result: 01100101
Decimal result: 101
Hexadecimal result: 0x65
```

Для введённых чисел чётность кодируется так:

```text
Номер числа:  8 7 6 5 4 3 2 1
Номер бита:   7 6 5 4 3 2 1 0
Бит:          0 1 1 0 0 1 0 1
```

Код решения:

```c
#include <stdio.h>


void print_byte(unsigned int value){
    for (int bit_index = 7; bit_index >= 0; bit_index--){
        printf("%u", (value >> bit_index) & 1u);
    }
}


int main(){
    unsigned int result = 0;

    for (int index = 0; index < 8; index++){
        int number;

        printf("Input number %d: ", index + 1);
        scanf("%d", &number);

        if (number % 2 == 0){
            result |= 1u << index;
        }
        else{
            result &= ~(1u << index);
        }
    }

    printf("Binary result: ");
    print_byte(result);
    printf("\n");

    printf("Decimal result: %u\n", result);
    printf("Hexadecimal result: 0x%02X\n", result);

    return 0;
}
```

Так как переменная `result` изначально равна нулю, все её биты сброшены. Поэтому ветку `else` в этом решении можно было бы не писать: для нечётного числа соответствующий бит и так остался бы равен нулю. Здесь ветка сохранена, чтобы явно показать оба действия из условия задачи — установку и сброс бита.
