# Занятие 4. Стек, указатели и массивы

На прошлом занятии мы использовали циклы, функции и побитовые операции. Сегодня разберём, что происходит с локальными переменными во время вызова функции, научимся передавать в функцию адрес переменной и познакомимся с массивами.

Сначала кратко рассмотрим основные области памяти программы, а затем сосредоточимся на автоматических локальных переменных и стеке вызовов. Динамическое выделение памяти на этом занятии не используем.

## Области памяти программы на примере STM32F303RE

В качестве конкретного примера рассмотрим микроконтроллер STM32F303RE. Он содержит 512 КиБ Flash-памяти по адресам от `0x08000000` до `0x0807FFFF` и 64 КиБ основной SRAM по адресам от `0x20000000` до `0x2000FFFF`.

```text
Flash

0x0807FFFF  +----------------------------------+
            |                                  |
            | Область инструкций программы     |
            |                                  |
0x08000000  +----------------------------------+

                         ...

SRAM

0x2000FFFF  +----------------------------------+
            | Стек                             |
            | растёт к меньшим адресам   ↓     |
            +----------------------------------+
            |                                  |
            | Свободная SRAM                   |
            |                                  |
            +----------------------------------+
            | Куча                             |
            | растёт к большим адресам   ↑     |
0x20000000  +----------------------------------+
```

Внутри каждой области меньшие адреса расположены снизу, а большие — сверху. Сами области показаны отдельно и не упорядочены по их числовым адресам. Область инструкций находится во Flash-памяти. Куча и стек находятся в SRAM: куча при использовании обычно растёт к большим адресам, а стек — к меньшим. Между ними остаётся свободная память.

Схема намеренно упрощена. Точные границы стека и кучи задаются настройками конкретного проекта, а во Flash и SRAM располагаются и другие данные. На этом занятии кучу практически не используем, а подробно рассматриваем только стек.

Источники для аппаратной карты памяти: [страница STM32F303RE](https://www.st.com/en/microcontrollers-microprocessors/stm32f303re.html), [datasheet STM32F303xD/E](https://www.st.com/resource/en/datasheet/stm32f303re.pdf) и [reference manual RM0316](https://www.st.com/resource/en/reference_manual/dm00043574.pdf).

## Стек

**Стек** — это структура данных, которая работает по принципу «последним добавлен — первым удалён». Такой принцип называют LIFO — `Last In, First Out`.

Стек можно представить как стопку тарелок: новую тарелку кладут сверху и первой снимают ту тарелку, которую положили последней.

```text
Добавить элемент
       ↓
    +-----+
    |  30 |  ← вершина стека
    +-----+
    |  20 |
    +-----+
    |  10 |
    +-----+
```

Программа использует **стек вызовов** для хранения информации, необходимой во время выполнения функций. Когда вызывается функция, для неё создаётся новый кадр стека. Когда функция завершает работу, её кадр удаляется.

## Кадр стека

**Кадр стека** — это часть стека вызовов, связанная с одним конкретным вызовом функции. В учебной модели кадр содержит:

- информацию, необходимую для возврата в вызывающую функцию;
- сохранённые значения некоторых регистров;
- параметры функции, если они размещены в стеке;
- локальные переменные функции;
- временные значения, необходимые для вычислений.

Рассмотрим цепочку из нескольких вызовов:

```c
void set_value(int *value, int new_value){
    *value = new_value;
}


void change_value(int *value){
    int new_value = 25;
    set_value(value, new_value);
}


void run_example(){
    int number = 10;
    change_value(&number);
}


int main(){
    run_example();

    return 0;
}
```

Во время выполнения `set_value` стек вызовов можно представить так. Последняя вызванная функция находится наверху, а первая функция `main` — в самом низу:

```text
+----------------------------------+  ← текущая вершина стека
| Кадр set_value                  |
| value — копия адреса number     |
| new_value = 25                  |
| возврат в change_value          |
+----------------------------------+
| Кадр change_value               |
| value — копия адреса number     |
| new_value = 25                  |
| возврат в run_example           |
+----------------------------------+
| Кадр run_example                |
| number = 10                     |
| возврат в main                  |
+----------------------------------+
| Кадр main                       |
| возврат в среду запуска         |
+----------------------------------+  ← низ показанной цепочки вызовов
```

Сначала завершается `set_value` и удаляется её кадр, затем управление возвращается в `change_value`. После завершения `change_value` удаляется её кадр, выполнение продолжается в `run_example`, а затем возвращается в `main`. Переменная `new_value` перестаёт существовать, но значение `number` остаётся изменённым, потому что функция `set_value` записала новое значение по его адресу.

Эта схема показывает порядок вложенных вызовов, а не направление роста адресов в памяти. Фактическое расположение кадров зависит от платформы и рассматривается ниже отдельно.

### Указатель стека и указатель кадра

Процессор и скомпилированная программа используют специальные регистры для работы со стеком:

- **указатель стека** (`stack pointer`, SP) указывает на текущую вершину стека и изменяется при добавлении или удалении данных;
- **указатель кадра** (`frame pointer`, FP), если он используется, служит стабильной точкой отсчёта внутри текущего кадра функции.

Условно указатель кадра отмечает одну границу кадра, а указатель стека — его текущую другую границу. Локальные переменные располагаются внутри этой области и могут находиться по смещениям относительно указателя кадра или указателя стека.

На многих платформах стек растёт от больших адресов к меньшим. Упрощённая схема такого стека выглядит следующим образом:

```text
Большие адреса

+----------------------------------+
| Кадр вызывающей функции          |
+----------------------------------+  ← условное начало текущего кадра, FP
| информация для возврата          |
| сохранённые значения             |
| локальные переменные             |
+----------------------------------+  ← текущая вершина стека, SP

Меньшие адреса
```

Это учебная модель, а не требование языка Си. Точное направление роста стека, порядок данных в кадре и использование указателя кадра зависят от процессора, соглашения о вызовах, компилятора и настроек оптимизации. Параметры могут передаваться через регистры, а некоторые локальные переменные могут храниться в регистрах или быть полностью устранены оптимизатором.

### Время жизни локальных переменных

Обычная локальная переменная существует только во время выполнения того блока, в котором она объявлена. Адрес такой переменной нельзя использовать после завершения функции.

Следующая функция ошибочна:

```c
int *get_value_address(){
    int value = 10;
    return &value;
}
```

После завершения функции `value` перестаёт существовать, поэтому возвращённый указатель больше не указывает на действующую переменную. Обращение по такому указателю приводит к неопределённому поведению.

## Адрес переменной и указатель

Каждая переменная занимает некоторое место в памяти и имеет адрес. Оператор `&` позволяет получить адрес переменной:

```c
int number = 10;
int *number_pointer = &number;
```

Запись `int *number_pointer` объявляет указатель на значение типа `int`. В переменной `number_pointer` хранится адрес переменной `number`.

Предположим для примера, что компилятор разместил переменные по следующим условным адресам:

| Переменная | Адрес самой переменной | Хранимое значение |
| --- | --- | --- |
| `number` | `0x1000` | `10` |
| `number_pointer` | `0x2000` | `0x1000` |

Тогда выражения имеют следующие значения:

```text
&number         == 0x1000
number_pointer  == 0x1000
*number_pointer == 10
&number_pointer == 0x2000
```

Адрес `0x1000` хранится внутри переменной `number_pointer`, но сама переменная-указатель находится по другому адресу — `0x2000`. Приведённые адреса выбраны только для объяснения: при реальном запуске программа получит другие адреса.

Оператор `*` перед именем указателя позволяет обратиться к значению по сохранённому адресу:

```c
*number_pointer = 25;
```

После этой команды значение переменной `number` станет равным `25`.

```text
Адрес 0x2000                              Адрес 0x1000
number_pointer                            number
+------------------+                     +----------+
|      0x1000      | ------------------> |    25    |
+------------------+                     +----------+
```

После изменения `number_pointer` по-прежнему содержит `0x1000`, а выражение `*number_pointer` теперь даёт значение `25`.

Символ `*` используется в двух похожих, но разных ситуациях:

- в объявлении `int *number_pointer` он показывает, что переменная является указателем;
- в выражении `*number_pointer` он выполняет разыменование — обращение к значению по адресу.

Указатель должен содержать адрес существующего объекта. Нельзя разыменовывать неинициализированный указатель или нулевой указатель.

## Передача параметров в функцию

В языке Си все параметры передаются **по значению**. Функция получает копию переданного аргумента.

```c
void change_value(int value){
    value = 25;
}
```

Если вызвать `change_value(number)`, функция изменит только свою локальную копию `value`. Переменная `number` в вызывающей функции не изменится.

Чтобы функция могла изменить исходную переменную, передадим её адрес:

```c
void change_value(int *value){
    *value = 25;
}
```

Вызов функции:

```c
int number = 10;
change_value(&number);
```

Указатель также передаётся по значению: функция получает копию адреса. Однако обе копии адреса указывают на одну и ту же переменную, поэтому запись через `*value` изменяет исходный объект.

### Обмен значений двух переменных

Передача адресов позволяет функции изменить сразу несколько переменных:

```c
void swap_values(int *first, int *second){
    int temporary = *first;
    *first = *second;
    *second = temporary;
}
```

Пример вызова:

```c
int a = 10;
int b = 20;

swap_values(&a, &b);
```

После вызова `a` будет равно `20`, а `b` — `10`.

## Установка и сброс бита через указатель

На прошлом занятии мы изменяли биты непосредственно в функции `main`. Теперь вынесем эти действия в отдельные функции. Чтобы функция изменила исходное значение, она принимает указатель на него.

```c
void set_bit(unsigned int *value, int bit_index){
    (*value) |= 1u << bit_index;
}


void reset_bit(unsigned int *value, int bit_index){
    (*value) &= ~(1u << bit_index);
}
```

Скобки в выражениях `(*value)` явно показывают, что побитовая операция применяется к значению по адресу, а не к самому указателю.

Пример использования:

```c
unsigned int value = 8;

set_bit(&value, 1);
reset_bit(&value, 3);
```

После установки бита `1` значение изменится с `00001000` на `00001010`. После сброса бита `3` получится `00000010`.

Функции предполагают, что индекс находится в диапазоне от `0` до `7`. Проверку пользовательского ввода выполним до их вызова.

## Массивы

**Массив** — это последовательность элементов одного типа, расположенных друг за другом. Размер массива задаётся при его создании.

```c
int numbers[5];
```

Массив `numbers` содержит пять элементов типа `int`. Их индексы начинаются с нуля:

```text
Индекс:       0       1       2       3       4
          +-------+-------+-------+-------+-------+
numbers:  |       |       |       |       |       |
          +-------+-------+-------+-------+-------+
```

Обратиться к элементу можно по индексу:

```c
numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;
```

Выход за границы массива приводит к неопределённому поведению. Для массива из пяти элементов допустимы только индексы от `0` до `4`.

Локальный массив, объявленный обычным способом внутри функции, в нашей учебной модели относится к кадру этой функции и существует до выхода из соответствующего блока. Как и для отдельных локальных переменных, компилятор может изменить фактическое размещение при оптимизации.

### Обработка массива в цикле

Цикл позволяет последовательно обработать все элементы массива:

```c
int numbers[5];

for (int index = 0; index < 5; index++){
    printf("Input number %d: ", index + 1);
    scanf("%d", &numbers[index]);
}
```

Для вывода элементов используется такой же диапазон индексов:

```c
for (int index = 0; index < 5; index++){
    printf("numbers[%d] = %d\n", index, numbers[index]);
}
```

### Массив и указатель

В большинстве выражений имя массива преобразуется в указатель на его первый элемент:

```c
int numbers[5];
int *first_element = numbers;
```

Записи `numbers` и `&numbers[0]` указывают на первый элемент массива. Индексация связана с разыменованием указателя:

```c
numbers[index]
*(numbers + index)
```

Эти два выражения обращаются к одному и тому же элементу.

При передаче массива в функцию фактически передаётся адрес его первого элемента:

```c
void increment_elements(int numbers[], int count){
    for (int index = 0; index < count; index++){
        numbers[index]++;
    }
}
```

Вызов функции:

```c
int numbers[5] = {10, 20, 30, 40, 50};
increment_elements(numbers, 5);
```

Функция изменяет элементы исходного массива. Знак `&` перед именем массива при вызове не нужен.

Размер массива автоматически не передаётся. Поэтому функция получает дополнительный параметр `count`. Внутри такой функции параметр `numbers` является указателем, и по нему нельзя надёжно определить количество элементов исходного массива.

## Задание 2 — Обмен значений

**Условие.** Напишите функцию `swap_values`, которая меняет местами значения двух целочисленных переменных. Введите два числа, вызовите функцию и выведите значения до и после обмена.

**Пример верного ввода и вывода:**

```text
Input first number: 10
Input second number: 25
Before: first = 10, second = 25
After: first = 25, second = 10
```

```c
#include <stdio.h>


void swap_values(int *first, int *second);

    int first;
    int second;

    scanf("%d", &first);

    printf("Input second number: ");
    scanf("%d", &second);

void swap_values(int *first, int *second){
    int temporary = *first;
    *first = *second;
    *second = temporary;
}
```

## Задание 3 — Изменение выбранного бита

**Условие.** Введите целое значение от `0` до `255`, номер бита от `0` до `7` и новое значение бита: `1` для установки или `0` для сброса. Для изменения исходного числа используйте функции `set_bit` и `reset_bit`, принимающие указатель. Выведите число до и после изменения в двоичном и десятичном виде.

**Пример верного ввода и вывода:**

```text
Input value from 0 to 255: 8
Input bit index from 0 to 7: 1
Input new bit value (0 or 1): 1
Before: 00001000 (8)
After:  00001010 (10)
```

Код решения:

```c
#include <stdio.h>


void print_byte(unsigned int value);
void set_bit(unsigned int *value, int bit_index);
void reset_bit(unsigned int *value, int bit_index);


int main(){
    unsigned int value;
    int bit_index;
    int bit_value;

    printf("Input value from 0 to 255: ");
    scanf("%u", &value);

    printf("Input bit index from 0 to 7: ");
    scanf("%d", &bit_index);

    printf("Input new bit value (0 or 1): ");
    scanf("%d", &bit_value);

    if (value > 255u || bit_index < 0 || bit_index > 7 || (bit_value != 0 && bit_value != 1)){
        printf("Incorrect input\n");
        return 1;
    }

    printf("Before: ");
    print_byte(value);
    printf(" (%u)\n", value);

    if (bit_value == 1){
        set_bit(&value, bit_index);
    }
    else{
        reset_bit(&value, bit_index);
    }

    printf("After:  ");
    print_byte(value);
    printf(" (%u)\n", value);

    return 0;
}


void print_byte(unsigned int value){
    for (int bit_index = 7; bit_index >= 0; bit_index--){
        printf("%u", (value >> bit_index) & 1u);
    }
}


void set_bit(unsigned int *value, int bit_index){
    (*value) |= 1u << bit_index;
}


void reset_bit(unsigned int *value, int bit_index){
    (*value) &= ~(1u << bit_index);
}
```

## Задание 4 — Ввод и обратный вывод массива

**Условие.** Создайте массив из пяти целых чисел. Напишите функцию `input_array` для ввода элементов и функцию `print_array_reverse` для их вывода в обратном порядке. Передавайте в функции массив и количество его элементов.

**Пример верного ввода и вывода:**

```text
Input number 1: 10
Input number 2: 20
Input number 3: 30
Input number 4: 40
Input number 5: 50
Reverse order: 50 40 30 20 10
```

Код решения:

```c
#include <stdio.h>


void input_array(int numbers[], int count);
void print_array_reverse(int numbers[], int count);


int main(){
    int numbers[5];

    input_array(numbers, 5);

    printf("Reverse order: ");
    print_array_reverse(numbers, 5);

    return 0;
}


void input_array(int numbers[], int count){
    for (int index = 0; index < count; index++){
        printf("Input number %d: ", index + 1);
        scanf("%d", &numbers[index]);
    }
}


void print_array_reverse(int numbers[], int count){
    for (int index = count - 1; index >= 0; index--){
        printf("%d", numbers[index]);

        if (index > 0){
            printf(" ");
        }
    }

    printf("\n");
}
```

## Задание 5 — Кодирование массива в битовую маску

**Условие.** Создайте массив из восьми целых чисел и заполните его с клавиатуры. Напишите функцию `encode_even_numbers`, которая получает массив, количество элементов и указатель на результат. Для каждого чётного числа функция должна установить бит с соответствующим индексом в `1`, а для каждого нечётного — сбросить его в `0`. Выведите полученную восьмибитовую маску в двоичном, десятичном и шестнадцатеричном виде.

Первому элементу массива соответствует бит `0`, второму — бит `1`, восьмому — бит `7`.

**Пример верного ввода и вывода:**

```text
Input number 1: 2
Input number 2: 3
Input number 3: 4
Input number 4: 5
Input number 5: 7
Input number 6: 8
Input number 7: 10
Input number 8: 11
Binary result: 01100101
Decimal result: 101
Hexadecimal result: 0x65
```

Код решения:

```c
#include <stdio.h>


void print_byte(unsigned int value);
void set_bit(unsigned int *value, int bit_index);
void reset_bit(unsigned int *value, int bit_index);
void input_array(int numbers[], int count);
void encode_even_numbers(int numbers[], int count, unsigned int *result);


int main(){
    int numbers[8];
    unsigned int result;

    input_array(numbers, 8);
    encode_even_numbers(numbers, 8, &result);

    printf("Binary result: ");
    print_byte(result);
    printf("\n");

    printf("Decimal result: %u\n", result);
    printf("Hexadecimal result: 0x%02X\n", result);

    return 0;
}


void print_byte(unsigned int value){
    for (int bit_index = 7; bit_index >= 0; bit_index--){
        printf("%u", (value >> bit_index) & 1u);
    }
}


void set_bit(unsigned int *value, int bit_index){
    (*value) |= 1u << bit_index;
}


void reset_bit(unsigned int *value, int bit_index){
    (*value) &= ~(1u << bit_index);
}


void input_array(int numbers[], int count){
    for (int index = 0; index < count; index++){
        printf("Input number %d: ", index + 1);
        scanf("%d", &numbers[index]);
    }
}


void encode_even_numbers(int numbers[], int count, unsigned int *result){
    *result = 0;

    for (int index = 0; index < count; index++){
        if (numbers[index] % 2 == 0){
            set_bit(result, index);
        }
        else{
            reset_bit(result, index);
        }
    }
}
```

В этой задаче массив передаётся в функцию как адрес первого элемента, а переменная `result` — как отдельный указатель на изменяемое значение. Функция записывает итог непосредственно в переменную, созданную в `main`.
