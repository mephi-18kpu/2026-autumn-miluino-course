# Занятие 1. Устройство первой программы на языке Си

На первом занятии разберём небольшую программу построчно. Она выводит сведения о себе, считывает целое число, определяет его знак и завершает работу.

Исходный файл занятия находится в каталоге `Занятие 1` и называется `task-1.c`.

## Общая структура программы

Программа содержит:

- подключение стандартного заголовочного файла;
- макрос с номером версии;
- прототип пользовательской функции;
- функцию `main`, с которой начинается выполнение программы;
- ввод целого числа;
- условные операторы;
- определение пользовательской функции.

Упрощённая структура исходного файла:

```c
#include <stdio.h>

#define VERSION 1


void print_prog_info(void);


int main(void){
    print_prog_info();

    return 0;
}


void print_prog_info(void){
    printf("Version: %d\n", VERSION);
}
```

## Как исходный код превращается в программу

До запуска исходный файл проходит несколько этапов:

```text
task-1.c
    |
    v
Препроцессор
    |
    v
Код после обработки #include и #define
    |
    v
Компилятор
    |
    v
Объектный файл с машинным кодом
    |
    v
Компоновщик
    |
    v
Исполняемый файл
```

**Препроцессор** обрабатывает директивы, начинающиеся с символа `#`, раскрывает макросы и подготавливает текст для компилятора.

**Компилятор** проверяет синтаксис и семантику программы и переводит функции в машинный код выбранной платформы.

**Компоновщик**, или линкер, объединяет объектные файлы программы с необходимыми библиотеками и создаёт исполняемый файл.

## Директива `#include`

Первая строка программы:

```c
#include <stdio.h>
```

`#include` — директива препроцессора. Она подключает содержимое заголовочного файла `stdio.h` в точку включения.

Имя `stdio` происходит от `standard input/output` — стандартный ввод и вывод. Заголовочный файл сообщает компилятору о функциях стандартной библиотеки, среди которых:

- `printf` — форматированный вывод;
- `scanf` — форматированный ввод.

Угловые скобки обозначают поиск заголовочного файла в системных каталогах компилятора:

```c
#include <stdio.h>
```

Собственные заголовочные файлы обычно подключаются в двойных кавычках:

```c
#include "point.h"
```

Важно различать заголовочный файл и реализацию библиотеки. `stdio.h` содержит необходимые объявления, типы и макросы, но обычно не вставляет в исходный файл реализацию `printf` или `scanf`. Готовые реализации этих функций находятся в стандартной библиотеке и присоединяются компоновщиком.

Если вызвать `printf` без правильного объявления, компилятор не сможет корректно проверить переданные аргументы и тип возвращаемого значения.

## Директива `#define`

Следующая строка объявляет макрос:

```c
#define VERSION 1
```

Во время работы препроцессора идентификатор `VERSION` заменяется последовательностью `1`:

```c
printf("Version: %d\n", VERSION);
```

После раскрытия макроса эта строка приблизительно выглядит так:

```c
printf("Version: %d\n", 1);
```

Макрос не является обычной переменной:

- для него не создаётся объект в памяти;
- у него нет типа языка Си;
- замена выполняется до компиляции;
- после директивы `#define` не ставится точка с запятой.

Имена макросов принято записывать в `UPPER_SNAKE_CASE`, чтобы визуально отличать их от переменных и функций.

Дополнительные пробелы между `VERSION` и `1` не влияют на смысл:

```c
#define VERSION     1
```

Они могут использоваться для визуального выравнивания нескольких похожих определений.

## Комментарии

Однострочный комментарий начинается с `//`:

```c
#define VERSION 1 // Текущая версия программы
```

Многострочный комментарий располагается между `/*` и `*/`:

```c
/*
    Функция выводит информацию о программе
*/
```

Комментарии предназначены для человека и не выполняются программой. На ранних этапах обработки исходного файла они заменяются пробельными символами, чтобы не влиять на синтаксическую структуру программы.

Хороший комментарий объясняет назначение решения или неочевидную причину, а не повторяет буквально написанную ниже команду.

## Объявление функции

Строка перед `main` является объявлением функции, или прототипом:

```c
void print_prog_info(void);
```

Разберём её части:

```text
void print_prog_info(void);
 |          |        |
 |          |        +-- функция не принимает параметры
 |          +----------- имя функции
 +---------------------- функция не возвращает значение
```

Точка с запятой показывает, что это только объявление. Тело функции будет записано позже.

Прототип сообщает компилятору:

- имя функции;
- тип возвращаемого значения;
- количество параметров;
- тип каждого параметра.

Благодаря прототипу функцию можно вызвать раньше, чем компилятор встретит её определение.

## Семантика объявления функции

Общая форма объявления:

```c
return_type function_name(parameter_type parameter_name);
```

Пример функции, принимающей два целых числа и возвращающей целое число:

```c
int add_numbers(int first, int second);
```

Здесь:

- `int` перед именем функции — тип результата;
- `add_numbers` — имя функции;
- первый `int first` — первый параметр;
- второй `int second` — второй параметр;
- точка с запятой завершает объявление.

Имена параметров в прототипе можно не указывать:

```c
int add_numbers(int, int);
```

Но имена помогают понять назначение параметров.

Для функции без параметров в современном коде на Си явно пишут `void`:

```c
void print_prog_info(void);
```

Запись с пустыми скобками:

```c
void print_prog_info();
```

в версиях языка до C23 означает, что сведения о параметрах не указаны. Поэтому форма `(void)` точнее и позволяет компилятору лучше проверять вызовы.

## Объявление, определение и вызов функции

Это три разные операции.

Объявление сообщает, что функция существует:

```c
void print_prog_info(void);
```

Определение содержит тело функции:

```c
void print_prog_info(void){
    printf("Version: %d\n", VERSION);
}
```

Вызов передаёт управление функции:

```c
print_prog_info();
```

После завершения `print_prog_info` выполнение продолжается со следующей команды вызывающей функции.

## Функция `main`

Функция `main` является точкой входа в обычную программу:

```c
int main(void){
    return 0;
}
```

Операционная система или среда выполнения начинает выполнение пользовательского кода с вызова `main`.

Разбор объявления:

- `int` — функция возвращает целое число;
- `main` — специальное имя точки входа;
- `(void)` — параметры не используются;
- `{` и `}` ограничивают тело функции.

Запись `return 0;` завершает функцию и сообщает среде запуска об успешном выполнении программы. Ненулевое значение обычно обозначает ошибку.

В исходном примере используется форма:

```c
int main(){
```

Для учебного кода на современном Си будем предпочитать более явную запись:

```c
int main(void){
```

## Инструкции и блоки

Большинство простых инструкций завершается точкой с запятой:

```c
print_prog_info();
return 0;
```

Фигурные скобки объединяют инструкции в блок:

```c
{
    print_prog_info();
    return 0;
}
```

Точка с запятой не ставится после заголовка функции или управляющей конструкции, если сразу начинается их блок:

```c
int main(void){
```

```c
if (number > 0){
```

## Переменная типа `int`

В программе создаётся локальная переменная:

```c
int number;
```

`int` — целочисленный тип, а `number` — имя переменной.

Переменная объявлена внутри `main`, поэтому доступна от места объявления до конца блока функции. Она называется локальной переменной.

До успешного ввода значение неинициализированной локальной переменной не определено. Поэтому использовать `number` можно только после того, как `scanf` успешно запишет в неё число.

## Вывод через `printf`

Простой вывод текста:

```c
printf("Input any number: ");
```

Строка в двойных кавычках называется строковым литералом.

Форматированный вывод значения:

```c
printf("Version: %d\t", VERSION);
```

`%d` — спецификатор формата для значения типа `int`. На его место подставляется следующий аргумент функции.

Управляющие последовательности начинаются с обратной косой черты:

| Последовательность | Действие |
| --- | --- |
| `\n` | Перейти на новую строку |
| `\t` | Вставить горизонтальную табуляцию |
| `\\` | Вывести обратную косую черту |
| `\"` | Вывести двойную кавычку внутри строки |

Строка

```c
printf("End of program");
```

не переводит курсор на новую строку. Обычно удобнее завершить текст символом `\n`:

```c
printf("End of program\n");
```

## Ввод через `scanf`

Ввод целого числа:

```c
scanf("%d", &number);
```

`%d` сообщает функции, что требуется прочитать значение типа `int`.

Оператор `&` получает адрес переменной:

```c
&number
```

`scanf` нужен адрес, потому что функция должна записать результат в переменную, созданную внутри `main`. Подробно адреса и указатели рассматриваются на последующих занятиях.

`scanf` возвращает количество успешно прочитанных значений. В первой программе можно предположить, что пользователь вводит корректное целое число. Более надёжный вариант проверяет результат:

```c
if (scanf("%d", &number) != 1){
    printf("Incorrect input\n");
    return 1;
}
```

Без проверки ошибочный ввод оставит переменную без корректно записанного значения.

## Условный оператор

Программа определяет знак введённого числа:

```c
if (number == 0){
    printf("Input zero number\n");
}
else if (number > 0){
    printf("Input positive number\n");
}
else{
    printf("Input negative number\n");
}
```

Ветви проверяются сверху вниз:

1. Если число равно нулю, выполняется первая ветвь.
2. Иначе проверяется, больше ли число нуля.
3. Если второе условие истинно, выполняется вторая ветвь.
4. Если оба условия ложны, число отрицательное и выполняется ветвь `else`.

Только одна ветвь этой конструкции будет выполнена.

### Сравнение и присваивание

Оператор равенства содержит два символа `=`:

```c
number == 0
```

Оператор присваивания содержит один символ:

```c
number = 0;
```

Это разные операции. Присваивание изменяет переменную, а сравнение проверяет равенство значений.

Другие операции сравнения:

| Оператор | Значение |
| --- | --- |
| `==` | Равно |
| `!=` | Не равно |
| `>` | Больше |
| `<` | Меньше |
| `>=` | Больше или равно |
| `<=` | Меньше или равно |

## Определение `print_prog_info`

В конце исходного файла находится определение пользовательской функции:

```c
void print_prog_info(void){
    printf("Version: %d\t", VERSION);
    printf("Author: user\n");
}
```

Функция:

- не получает параметров;
- не возвращает значение;
- выводит номер версии;
- выводит обезличенное обозначение автора.

Тип `void` перед именем означает отсутствие возвращаемого значения. В такой функции можно использовать `return;` без значения для досрочного завершения, но в конце короткой функции он не обязателен.

## Порядок выполнения программы

Директивы препроцессора и объявления функций не выполняются как обычные команды. После создания исполняемого файла выполнение происходит в следующем порядке:

1. Среда запуска вызывает `main`.
2. `main` вызывает `print_prog_info`.
3. `print_prog_info` выводит номер версии и сведения об авторе.
4. Управление возвращается в `main`.
5. Программа выводит приглашение для ввода.
6. `scanf` записывает целое число в локальную переменную.
7. Конструкция `if` выбирает сообщение в зависимости от знака числа.
8. Программа выводит сообщение о завершении.
9. `return 0` завершает `main`.


## Что происходит после препроцессора

Препроцессор раскрывает макрос `VERSION`, обрабатывает `#include` и удаляет комментарии. Сильно упрощённый фрагмент после обработки макроса выглядит так:

```c
void print_prog_info(void);


int main(void){
    print_prog_info();

    int number;
    printf("Input any number: ");
    scanf("%d", &number);

    if (number == 0){
        printf("Input zero number\n");
    }
    else if (number > 0){
        printf("Input positive number\n");
    }
    else{
        printf("Input negative number\n");
    }

    printf("End of program\n");

    return 0;
}


void print_prog_info(void){
    printf("Version: %d\t", 1);
    printf("Author: user\n");
}
```

Это только учебная иллюстрация. Реальный результат работы препроцессора значительно больше, потому что в него попадает содержимое системных заголовочных файлов. При этом реализация `printf` не вставляется непосредственно в исходный текст: компоновщик связывает вызов с реализацией из стандартной библиотеки.

Для просмотра результата работы препроцессора GCC можно использовать команду:

```text
gcc -E task-1.c
```

## Итоговый вариант программы

В следующем варианте уточнены объявления функций, добавлена проверка результата `scanf` и перевод строки после последнего сообщения:

```c
#include <stdio.h>

#define VERSION 1


void print_prog_info(void);


int main(void){
    print_prog_info();

    int number;

    printf("Input any number: ");

    if (scanf("%d", &number) != 1){
        printf("Incorrect input\n");
        return 1;
    }

    if (number == 0){
        printf("Input zero number\n");
    }
    else if (number > 0){
        printf("Input positive number\n");
    }
    else{
        printf("Input negative number\n");
    }

    printf("End of program\n");

    return 0;
}


void print_prog_info(void){
    printf("Version: %d\t", VERSION);
    printf("Author: user\n");
}
```
