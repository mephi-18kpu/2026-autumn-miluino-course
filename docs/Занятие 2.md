# Занятие 2. Ввод, вывод и простые вычисления

На прошлом занятии мы использовали `printf`, `scanf` и переменную типа `int`. Сегодня научимся вводить несколько значений, вычислять результат и выводить его в удобном виде.

## Типы данных

Тип определяет, какие значения может хранить переменная. В столбце «Спецификатор» указан формат для `scanf` и `printf`; если они различаются, оба формата подписаны отдельно.

| Тип | Что хранит | Пример объявления | Размер | Спецификатор |
| --- | --- | --- | ---: | --- |
| `char` | Целочисленный код одного символа | `char letter;` | 1 | `%c` |
| `signed char` | Целое число со знаком | `signed char a;` | 1 | `%hhd` |
| `unsigned char` | Целое число без знака | `unsigned char a;` | 1 | `%hhu` |
| `short` (`short int`) | Целое число со знаком | `short a;` | 2 | `%hd` |
| `unsigned short` | Целое число без знака | `unsigned short a;` | 2 | `%hu` |
| `int` (`signed int`) | Целое число со знаком | `int minutes;` | 4 | `%d` |
| `unsigned int` | Целое число без знака | `unsigned int a;` | 4 | `%u` |
| `long` (`long int`) | Целое число со знаком | `long a;` | 4 (Windows) или 8 (многие Unix-подобные системы) | `%ld` |
| `unsigned long` | Целое число без знака | `unsigned long a;` | 4 или 8 | `%lu` |
| `long long` (`long long int`) | Целое число со знаком | `long long a;` | 8 | `%lld` |
| `unsigned long long` | Целое число без знака | `unsigned long long a;` | 8 | `%llu` |
| `float` | Вещественное число с плавающей точкой | `float price;` | 4 | `%f` |
| `double` | Вещественное число с плавающей точкой | `double distance;` | 8 | `scanf`: `%lf`; `printf`: `%f` |
| `long double` | Вещественное число с плавающей точкой | `long double a;` | 8 или 16 | `%Lf` |

В колонке «Размер» указано количество байтов. Это **типичные**, а не гарантированные языком размеры для современных 64-битных систем: точное значение даёт `sizeof(тип)`. В частности, `long` занимает 4 байта в Microsoft C и обычно 8 байт в 64-битной модели LP64; `long double` в Microsoft C занимает 8 байт и не превосходит `double` по точности. Один байт в Си равен размеру `char` и на рассматриваемых системах содержит 8 бит.

`char` — отдельный от `signed char` и `unsigned char` тип. Таблица показывает ввод символа через `%c`; числовые форматы двух других типов показывают их как числа. При вызове `printf` значения `float` автоматически передаются как `double`, поэтому для обоих используется `%f`.

Для полноты картины в Си есть и другие категории типов. У многих из них **нет одного общего спецификатора** для `scanf` и `printf`:

| Тип или категория | Пример | Спецификатор |
| --- | --- | --- |
| `void` (отсутствие значения) | `void print_info(void);` | Нет: значение типа `void` не вводят и не выводят |
| Перечисление `enum` | `enum Color { RED, GREEN };` | Нет общего: для вывода можно преобразовать значение к подходящему целому типу |
| Массив | `int numbers[5];` | Нет общего: элементы вводят и выводят по отдельности |
| Строка как массив `char` | `char word[20];` | `scanf`: `%19s` для этого массива; `printf`: `%s` |
| Указатель | `int *p;` | Для адреса объекта: `printf("%p", (void *)p)`; `%p` существует и в `scanf`, но требует переменную типа `void *` и редко нужен новичкам |
| Структура `struct` | `struct Point { int x; int y; };` | Нет общего: работают с полями по отдельности |

Для массива или структуры нет одного спецификатора: их элементы или поля вводят и выводят по отдельности. Остальные виды типов пока достаточно узнавать по названию; подробно работать с ними будем на следующих занятиях.

**На этом занятии** используем `int`, `float`, `char`, а в последнем задании — строку как массив `char`. Дробное число в примерах вводим через точку: `12.5`, а не `12,5`. Для `scanf` тип переменной и спецификатор должны соответствовать друг другу; совпадение буквы формата у `scanf` и `printf` не означает, что правила передачи аргументов у них одинаковы.

## Математические операции

| Операция | Запись | Пример | Результат |
| --- | --- | --- | --- |
| Сложение | `+` | `7 + 2` | `9` |
| Вычитание | `-` | `7 - 2` | `5` |
| Умножение | `*` | `7 * 2` | `14` |
| Деление с дробным результатом | `/` | `7.0 / 2` | `3.5` |
| Целочисленное деление | `/` | `7 / 2` | `3` |
| Остаток от деления | `%` | `7 % 2` | `1` |

Если **оба числа целые**, оператор `/` даёт целую часть результата: `7 / 2` равно `3`. Если хотя бы одно число дробное, результат деления будет дробным: `7.0 / 2` равно `3.5`. Оператор `%` применяют к целым числам: `135 % 60` равно `15`.

Скобки меняют порядок вычислений: `2 * (3 + 4)` равно `14`. Без скобок умножение, деление и остаток выполняются раньше сложения и вычитания. Для отрицательного числа можно написать `-a`. Записи `a++`, `a--`, `a += 2` и `a *= 2` также изменяют значение переменной, но в сегодняшних задачах они не обязательны. Символ `^` **не** означает возведение в степень в Си.

## Ввод и вывод

Библиотека `<stdio.h>` предоставляет функции `printf` для вывода и `scanf` для ввода:

```c
#include <stdio.h>

int main(){
    int number;

    printf("Input a number: ");
    scanf("%d", &number);

    printf("You entered: %d\n", number);

    return 0;
}
```

- В `scanf` обычно передаём **адрес** переменной: `&number`. В `printf` передаём её **значение**: `number`.
- Форматные обозначения должны соответствовать значениям: `%d` — `int`, `%f` — `float` при вводе, `%c` — `char`. При выводе `%.2f` показывает два знака после точки.
- `\n` переводит вывод на новую строку; `\t` вставляет табуляцию.
- Несколько значений можно считать одним вызовом: `scanf("%d %d", &a, &b);`.
- Для символа после ввода числа удобно писать `scanf(" %c", &operation);`. Пробел перед `%c` пропускает оставшиеся пробелы и перевод строки.

Пока предполагаем, что пользователь вводит данные указанного типа. Обработку ошибочного ввода разберём отдельно.

## Задание 1 — Прямоугольник

**Условие.** Введите целые длину и ширину прямоугольника. Выведите его площадь и периметр. Для начала используйте положительные значения сторон.

**Пример верного ввода и вывода:**

```text
Input length: 5
Input width: 3
Area: 15
Perimeter: 16
```

Код решения:

```c
#include <stdio.h>


int main(){
    // Считаем стороны прямоугольника
    int length;
    int width;

    printf("Input length: ");
    scanf("%d", &length);

    printf("Input width: ");
    scanf("%d", &width);

    // Выведем результаты
    printf("Area: %d\n", length * width);
    printf("Perimeter: %d\n", 2 * (length + width));

    return 0;
}
```


## Задание 2 — Время в минутах

**Условие.** Введите неотрицательное количество минут. Выведите число полных часов и оставшихся минут. Подумайте, какие две операции помогут разделить `135` минут на `2` часа и `15` минут.

**Пример верного ввода и вывода:**

```text
Input number of minutes: 135
Hours: 2
Minutes: 15
```

Код решения:

```c
#include <stdio.h>


int main(){
    // Считаем время в минутах
    int total_minutes;
    printf("Input number of minutes: ");
    scanf("%d", &total_minutes);

    // Вычислим часы и оставшиеся минуты
    int hours = total_minutes / 60;
    int minutes = total_minutes % 60;

    // Выведем результат
    printf("Hours: %d\n", hours);
    printf("Minutes: %d\n", minutes);

    return 0;
}
```


## Задание 3 — Покупка и сдача

**Условие.** Введите неотрицательные цену покупки и сумму, которую дал покупатель. Если денег хватает, выведите сдачу. Иначе выведите, сколько денег не хватает. Дробные суммы вводите через точку.

**Примеры верного ввода и вывода:**

```text
Input price: 80.50
Input received money: 100
Change: 19.50
```

```text
Input price: 80.50
Input received money: 50
Not enough: 30.50
```

Код решения:

```c
#include <stdio.h>


int main(){
    // Считаем цену и полученную сумму
    float price;
    float money;

    printf("Input price: ");
    scanf("%f", &price);

    printf("Input received money: ");
    scanf("%f", &money);

    // Выведем сдачу или недостающую сумму
    if (money >= price){
        printf("Change: %.2f\n", money - price);
    }
    else{
        printf("Not enough: %.2f\n", price - money);
    }

    return 0;
}
```

## Задание 4 — Простой калькулятор

**Условие.** Введите два числа и символ операции (`+`, `-`, `*` или `/`). Выведите результат. Если делитель равен нулю или операция неизвестна, выведите сообщение вместо результата.

**Примеры верного ввода и вывода:**

```text
Input first number: 8
Input second number: 2
Input operation (+, -, *, /): /
Result: 4.00
```

```text
Input first number: 8
Input second number: 0
Input operation (+, -, *, /): /
Cannot divide by zero
```

Код решения:

```c
#include <stdio.h>


int main(){
    // Считаем числа и знак операции
    float a;
    float b;
    char operation;

    printf("Input first number: ");
    scanf("%f", &a);

    printf("Input second number: ");
    scanf("%f", &b);

    printf("Input operation (+, -, *, /): ");
    scanf(" %c", &operation);

    // Выполним выбранную операцию
    if (operation == '+'){
        printf("Result: %.2f\n", a + b);
    }
    else if (operation == '-'){
        printf("Result: %.2f\n", a - b);
    }
    else if (operation == '*'){
        printf("Result: %.2f\n", a * b);
    }
    else if (operation == '/'){
        if (b == 0){
            printf("Cannot divide by zero\n");
        }
        else{
            printf("Result: %.2f\n", a / b);
        }
    }
    else{
        printf("Unknown operation\n");
    }

    return 0;
}
```


## Задание 5 — Приветствие по имени

**Условие.** Введите своё имя одним словом. Программа должна вывести `Hello, <имя>`, подставив вместо `<имя>` введённое значение.

**Пример верного ввода и вывода:**

```text
Input your name: Anna
Hello, Anna
```

Код решения

```c
#include <stdio.h>


int main(){
    // Считаем имя из консоли
    char name[100];
    printf("Input your name: ");
    scanf("%99s", name);

    // Выведем приветствие
    printf("Hello, %s\n", name);

    return 0;
}
```

`%s` считывает строку до первого пробела или перевода строки. Число `99` ограничивает длину ввода для массива `name`, в котором нужно оставить место для завершающего символа строки. В отличие от отдельной числовой переменной, при передаче массива `name` в `scanf` знак `&` перед его именем не нужен.
